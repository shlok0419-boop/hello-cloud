Command Reference

Commands I practiced in the Ubuntu VM and in this project. Use man command or command --help for full options.

Linux: Navigation and Files

CommandWhat it does
pwdPrint the current directory
ls -laList all files, including hidden ones, with details
cd ~Go to your home directory
cd ..Go up one directory
mkdir -p a/b/cCreate nested directories
touch file.txtCreate an empty file
cp -r src/ dest/Copy a directory recursively
mv old.txt new.txtMove or rename a file
rm -r folder/Delete a directory and its contents
treeShow a directory structure
du -sh folder/Show the size of a folder
df -hShow disk space

Linux: Viewing and Searching

CommandWhat it does
cat file.txtPrint a whole file
less file.txtView a file page by page (press q to quit)
head -n 20 fileShow the first 20 lines
tail -f log.txtFollow a file as it grows
grep -ri "todo" .Search recursively for text, ignoring case
find . -name "*.html"Find files by name
echo "hi" > file.txtWrite text, overwriting the file
echo "hi" >> file.txtAppend text to a file
cmd1 | cmd2Pipe the output of one command into another

Linux: Permissions

CommandWhat it does
ls -l fileShow permissions and owner
chmod 600 secret.txtOwner can read and write only
chmod 755 script.shOwner has full access; others can read and run
chmod +x script.shMake a file executable
chown user:group fileChange owner and group

Read = 4, write = 2, execute = 1. Add them for owner, group, and others, so 7 is rwx, 6 is rw-, and 5 is r-x.

Linux: Processes, Packages, and Services

CommandWhat it does
ps auxList all running processes
top / htopLive view of processes and resource use
kill PIDAsk a process to stop
kill -9 PIDForce a process to stop
sleep 300 &Run a command in the background
sudo apt updateRefresh the package list
sudo apt install -y treeInstall a package
sudo systemctl status sshCheck a service's status
journalctl -u ssh -n 30Show recent logs for a service

Linux: Networking and SSH

CommandWhat it does
hostname -IShow the machine's IP addresses
ip addrShow network interfaces and addresses
ip routeShow the routing table and default gateway
ss -tulpnShow listening ports and their processes
ping -c 4 google.comTest connectivity
traceroute google.comShow the path to a host
nslookup google.comQuery DNS
dig google.com +shortShort DNS lookup
ssh-keygen -t ed25519Create an SSH key pair
ssh-copy-id user@hostInstall your public key on a server
ssh user@hostLog in to a server

Git

CommandWhat it does
git config --global user.name "Name"Set your commit author name
git init -b mainStart a repository on the main branch
git statusShow changed and staged files
git add fileStage a file
git commit -m "message"Save staged changes as a commit
git log --oneline --graph --allShow history and branches
git diffShow unstaged changes
git switch -c feature/xCreate and switch to a branch
git switch mainSwitch to another branch
git merge feature/xMerge a branch into the current one
git remote add origin URLConnect to a remote repository
git push -u origin mainUpload commits and set the upstream branch
git pullDownload and merge remote changes
git restore --staged fileUnstage a file
git commit --amend -m "msg"Change the last commit message
git revert COMMITCreate a commit that undoes another commit
git stash / git stash popSave and restore uncommitted changes

Example workflow

git switch -c feature/about-page
echo "<h1>About Me</h1>" > about.html
git add about.html
git commit -m "Add about page"
git switch main
git merge feature/about-page
git push
